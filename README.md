## Projects

**Sambhaash AI** | Distributed voice-based lead engagement system
Client dashboard to a fault-tolerant Twilio backend with real-time STT/TTS pipelines. Redis-backed async task queue for lead scoring, retries and dead-letter queues. *3rd Place Globally, Sarvam AI Track.*
[Live](https://sambhaash-ai.vercel.app/) | [Code](https://github.com/prajwal-priyadarshan/Sambhaash_AI)

**RepoGuardian AI** | Automated code analysis platform
React client and FastAPI backend that analyze repositories for complexity, structure and maintainability, using the GitHub API and LLMs with PostgreSQL/Supabase.
[Live](https://repo-guardian-ai.vercel.app/) | [Code](https://github.com/prajwal-priyadarshan/RepoGuardian_ai)

**StockSense AI** | Multi-agent investment analysis platform
Containerized multi-agent system orchestrating technical, fundamental, news and sentiment analysis via LangGraph, with FastAPI, PostgreSQL, Redis, Docker and RAG-backed retrieval.
[Code](https://github.com/prajwal-priyadarshan/StockSense-AI)
